# Silent Signal

Silent Signal is a PWA prototype for INF 654. It is a safe, anonymous space
where people can share what's happening in their world or their community.

Pages: Feed (index.html), Submit, Post Details, and Guidelines.
Built with HTML, Materialize CSS, and a little JavaScript.

## AI Use
I used Perplexity AI to help develop and debug the code and to assist in areas of uncertainty. The app idea, design choices, and site content are my own.
